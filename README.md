## 📌 Project Overview

The **Doctor Booking System** is a web-based healthcare appointment
management platform designed to simplify the process of connecting
patients with doctors.

The system allows administrators to manage doctors, disease categories,
doctor schedules, patient capacity and SMS logs.

Patients can register, select their disease category, view suitable
doctors, check doctor availability, book appointments, receive queue
information, upload medical reports and manage their booking history.

Doctors can securely log in and view their daily patient queue and
appointment information.

---

# 🏥 Doctor Booking System

A web-based Doctor Booking System developed using PHP, MySQL, HTML, CSS and JavaScript.


## ✨ Main Features

- 👨‍⚕️ Doctor Management
- 👤 Patient Registration & Login
- 🏥 Disease Category Selection
- 📅 Doctor Appointment Booking
- 🔢 Automatic Queue Number
- ⏰ Appointment Time Calculation
- 📱 SMS Notifications
- 📄 Medical Report Upload
- 🤖 AI Medical Report Analysis
- 📊 Admin Dashboard

## 🛠️ Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- AI API
- SMS API
